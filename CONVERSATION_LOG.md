# Aurora — conversation log & build notes

This file summarizes what was discussed and decided while building this app, so you have a full record of the requirements even after you close the chat.

---

## Original request

> "Can you make a carbon copy of an app (status - sim but social media) for me? Basically make a new app that perfectly replicates everything in there."

Reference app: **status — sims but social media**
(Google Play link: https://play.google.com/store/apps/details?id=link.socialai.app · https://www.statusai.com/)

Core mechanics of the reference app that were replicated in Aurora (this project):
- Feed of AI-generated posts, follower reactions
- Personas + fandoms
- DMs
- Energy system (~60/day, regen every ~5 min in reference; we made it 200/effectively-unlimited for solo use)
- Humour + Aura points (per-post deltas)
- Cancellation events
- Read receipts, typing indicators

## Confirmed requirements (from the user's answers)

1. **Platform:** downloadable Android app.
2. **AI characters:** real LLM-powered, plug in an API key so followers improvise genuinely.
3. **Scope:** full clone — feed, personas, fandoms, DMs w/ read receipts, energy system, aura/humour points, cancellation events, monetization scaffolding (present but disabled).
4. **Content rating:** edgier / mature themes allowed.
5. **No paywall.** Single-user, unlocked.
6. **Not "yes-men" AI.** Real personalities with room for growth and change.
7. **Compile the work into a single downloadable file** so the user can grab it even if credits run out mid-build.

---

## What was NOT copied (and why)

- Status's proprietary UI assets, icons, copywriting, and specific characters were **not** reproduced. Those are copyrighted.
- Aurora is a **new app in the same genre** with an original visual identity, original 15-character roster, and original 10 fandoms.

## Free vs paid LLM discussion

We agreed that **multiple free API keys used together** is the best approach:

- **Google Gemini** — ~1500 free requests/day (`gemini-2.0-flash`, `gemini-2.5-flash`)
- **Groq** — ~14,400 free requests/day, extremely fast (Llama 3.3 70B etc.)
- **Cerebras** — free tier, fastest inference on the planet
- **OpenRouter** — has multiple `:free` suffixed models (DeepSeek, Llama, Gemma, Hermes 405B)
- **Mistral La Plateforme** — free tier
- **Together AI** — small free credit + some free endpoints
- **Ollama** — 100% local, unlimited, best for uncensored personalities

**Paid fallbacks (optional):** OpenAI GPT-4o-mini, Anthropic Claude Haiku.

Aurora ships with a **multi-provider router** that:
- Rotates through configured providers automatically (`round_robin` / `least_used` / `pinned_only`)
- Fails over on rate-limit (429) or errors with a 3-minute cooldown
- **Pins each character to a preferred provider/model** so different followers sound like they're being generated by different models — this makes voices distinct rather than same-model-different-prompt.
- Has a "Test all providers" button in Settings that pings each key and reports green/red.

Net effect: with Gemini + Groq + OpenRouter free keys all pasted in, you're looking at **30,000+ free LLM calls per day combined** — orders of magnitude more than a solo player triggering ~60–200 actions/day could ever spend. Effectively unlimited, forever, zero dollars.

## Personality system

Every character has:

- **Big-Five traits** (openness, conscientiousness, extraversion, agreeableness, neuroticism)
- **Archetype** (e.g. "chaotic gremlin flirt", "world-weary cynic", "gothic novel enjoyer", "himbo motivator", "terminally online goblin", "aloof artiste", "insufferable film bro", "righteous firebrand", "soft-launch grifter", "chill uncle", "mystic aesthete", "pure bit account", "boundary-having friend", "aloof scenester", "meta-ironic mystic")
- **Values, quirks, taboos** — injected into every system prompt
- **Humour style** (dry, absurd, mean, wholesome, etc.)
- **Edge level** (0..1 — how spicy they can get)
- **Per-persona relationship state**: affinity (-100..100), trust, drama, interactions, grudges, fond memories, status (stranger → acquaintance → follower → friend → bestie → rival → nemesis → ex-friend)

The system prompt explicitly forbids sycophancy:
> "You are NOT an assistant. You are NOT helpful. You have your own life, opinions, moods, and grudges. Do not be a yes-man. If you disagree, disagree. If someone is boring you, say so. Never break character. Never say 'as an AI' or apologise for having opinions."

After every interaction, a small state-tracker LLM call updates the character's relationship with the user — issuing deltas to affinity/trust/drama, possibly adding a grudge or fond memory, and possibly upgrading/downgrading relationship status. There's a deterministic heuristic fallback if the LLM refuses.

## Monetization / paywall

Every monetization flag defaults **unlocked**:
- `settings.monetizationUnlocked = true` (ships true)
- Energy cap set to 200 with 9999/day (effectively unlimited)
- All features unlocked from first launch

The scaffolding exists in code so you could add gates later — but by default there are none.

## How to actually get this on your phone

Three options (documented in `README.md`):

### A. Expo Go (fastest, no compile)
1. Install Node 18+ on your PC.
2. Install "Expo Go" from Play Store on your Android.
3. In this folder: `npm install`, then `npx expo start`.
4. Scan the QR code with Expo Go. App runs.

### B. Real installable APK
1. `npm install -g eas-cli`
2. `eas login` (free Expo account)
3. `eas build -p android --profile preview`
4. ~10 min later EAS emails you an APK link. Install and delete the project — the APK stays.

### C. + Ollama for fully local/uncensored
1. On your PC, install Ollama and pull a model (`ollama pull dolphin-mistral` for zero-filter).
2. Find PC's LAN IP.
3. Aurora → Settings → Ollama → paste `http://<lan-ip>:11434`, enable it.
